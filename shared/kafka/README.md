# Shared Kafka Toolkit

STAR

**Situation:** Multiple clouds expose Kafka compatible or Kafka adjacent streaming systems such as MSK, Event Hubs Kafka endpoint, Pub/Sub through Beam, and OCI Streaming.

**Task:** Provide local producer and consumer examples that demonstrate clean event contracts before deploying to managed cloud services.

**Action:** Implemented event envelope producer, validation consumer, schema examples, and Docker Compose integration.

**Result:** Recruiters and engineers can run the streaming examples locally and map the same concepts to AWS, Azure, GCP, and OCI projects.
